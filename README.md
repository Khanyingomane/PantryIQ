PantryIQ — Smart Pantry Manager

Overview:
PantryIQ is a Java-based Android application developed for the Mobile Application Development assignment. 
It is designed to help users manage pantry ingredients, track available quantities, and discover recipes that can be prepared using ingredients they have available.

Project Objectives:
- Add, view, edit, and remove pantry ingredients.
- Store pantry information persistently.
- Suggest recipes based on available ingredients and quantities.
- Display recipe details and required ingredients.
- Provide a simple, user-friendly interface.

Technology Stack:
- Language: Java
- Platform: Android
- User Interface: XML layouts
- Database: SQLite (planned)
- Version Control: Git and GitHub

Development Status:
The initial Android Studio project has been created and uploaded to GitHub. Application features will be implemented incrementally as development progresses.

Project Structure:
- "app/" — Android application source code and resources.
- "gradle/" — Gradle Wrapper files.
- "build.gradle.kts" — Project build configuration.
- "settings.gradle.kts" — Gradle project settings.
